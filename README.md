🤖 NOVA AI — Intelligent AI Assistant

NOVA AI is a Django-based, ChatGPT-inspired AI assistant designed to provide a modern, interactive, and personalized conversational experience. 🚀

💬 Smart Conversations — Chat with NOVA through a clean and intuitive conversational interface designed for natural interactions.

🧠 AI-Powered Experience — Built as a foundation for integrating advanced AI capabilities, intelligent responses, and future assistant features.

📂 Conversation Management — Create new chats, rename conversations, delete unwanted conversations, and organize your interaction history.

🎨 Modern UI — A polished and responsive interface with Dark Mode and Light Mode for a comfortable experience in any environment.

👤 User Experience — Includes user profiles, authentication, and personalized interaction features.

⚙️ Django Backend — Built with Django to provide a scalable and structured backend architecture that can grow as NOVA evolves.

🔮 Future-Ready Architecture — NOVA is being developed with plans for advanced capabilities such as AI tools, image generation, file/library management, sharing, settings, and other intelligent assistant features.

🌱 Continuous Development — NOVA is an evolving project focused on transforming a basic AI chatbot into a complete, real-world AI assistant platform.

✨ NOVA AI — Your intelligent companion for conversation, creativity, productivity, and beyond.
